# Карта диска

Аналог SequoiaView для macOS: показывает диск или папку картой из прямоугольников. Площадь плитки пропорциональна размеру.

Сборка: `./build.sh` (нужны только Command Line Tools). Приложение: `build/Карта диска.app`.
Проверки: `DiskMap --selftest` (ядро), `DiskMap --flowtest` (удаление и пересчёт на временной папке), `DiskMap --uitest <папка> <куда снимки>`.

## Управление картой

- Щелчок: выбрать файл. С ⌥: выбрать его папку.
- Двойной щелчок, щипок, колесо мыши: на уровень глубже. ⌫, щипок обратно: наверх.
- Стрелки: ↑ родитель, ↓ обратно вглубь, ← → соседи. Enter: приблизить выбранное.
- Пробел: Quick Look. ⌘⌫: в Корзину. ⌥⌘⌫: удалить навсегда. Оба действия спрашивают подтверждение.
- ⌘[ и ⌘]: назад и вперёд. ⌘1…⌘5: режим цвета. ⌘K: подушки или плоские плитки. ⌘L: подписи. ⇧⌘H: рамки папок.
- ⌘F: поиск по имени. Esc сбрасывает фильтр. ⌘R: пересканировать. ⇧⌘R: только выбранную папку.
- ⌘E: карта в PNG. ⇧⌘E: список файлов в CSV. Папку можно перетащить в окно или на значок в Dock.

## Боковая панель

- Дерево: папки с долями, сортировка по любой колонке.
- Типы: категории и расширения. Щелчок оставляет на карте только этот тип.
- Крупные: 3000 самых больших файлов, сортировка по размеру и дате, учитывает поиск и фильтр.
- Дубликаты: файлы от 1 МБ, сравнение по SHA-256. «Выбрать копии» оставляет самый старый файл группы.

## Как считается

- По умолчанию размер занятого на диске места, в меню «Вид» можно включить логический.
- Жёсткие ссылки считаются один раз. Символические ссылки не раскрываются.
- Другие тома не сканируются. Данные системного тома считаются один раз, через /Users и другие firmlink-папки.
- Файлы iCloud не скачиваются: те, что только в облаке, занимают 0.
- На карте диска плитка «Не просканировано» показывает разницу между занятым и найденным: снимки APFS, очищаемое место и папки без доступа.
- Клоны APFS считаются как обычные файлы, поэтому реальное занятое место может быть меньше, а удаление такого дубликата может не освободить место.

## Доступ

Для полного скана системного диска включи программе «Полный доступ к диску»: Настройки → Конфиденциальность и безопасность. Подпись локальная, поэтому после каждой пересборки разрешение надо выдавать заново.

Корень карты и системные папки (/System, /usr, /bin, /sbin) удалить из программы нельзя.
